# G2P for Metro — 리뷰 기준과 페르소나

앱을 까다로운 사용자 관점에서 평가하기 위한 기준이다. 리뷰어는 시뮬레이션이다(실제 사람이 아니다).
통과 기준: 다섯 명 모두 종합 4.5점 이상(5점 만점).

## 평가 항목 (각 1~5점, 0.5 단위)

| 항목 | 보는 것 | 5점의 모습 |
|---|---|---|
| 사용성 | 첫 사용 이해도, 탭 수, 힌트와 실제 동작의 일치, 실수 방지와 되돌리기 | 설명 없이 쓴다. 출근 한 번에 탭 3~4번. 실수해도 잃는 것이 없다 |
| 편의성 | 자동화 정도(출발역 추정, 자동 탑승, 자동 환승 진행, 자동 재조회), 입력 최소화, 폰 설정 | 주머니 속 폰을 꺼낼 일이 없다 |
| 디자인 | 576×288 단색 녹색·고정 글꼴 제약 안에서 위계, 가독성, 여백, 일관성, 글리프, 문구 톤 | 한눈에 읽힌다. 조잡한 기호나 잘린 글자가 없다 |
| 정보 신뢰성 | 위치·도착 시각의 정확도, 추정의 정직한 표시, 데이터 지연 처리, 경로 이탈 처리 | 틀린 안내를 하지 않는다. 모르면 모른다고 한다 |
| 성능·안정성 | 갱신 주기와 실제 지연, 장시간 사용 안정성, 폭증·강제 종료 없음, 배터리·통신량 | 한 시간 타도 끊기지 않는다. 수치로 증명된다 |
| 실용성·경제성 | 실제 통근 적합성, 노선 커버리지, 운영비, API 한도, 유지보수 부담 | 매일 공짜로 쓴다. 관리할 것이 거의 없다 |

종합 점수는 평균이 아니라 리뷰어의 판단이다(0.1 단위). 근거를 댄다.

## 페르소나 (30대 테크 리뷰어 다섯 명)

1. **한서준 (34) · 인터랙션 해부가** — 전 모바일 UX 리서처, 테크 유튜버. 탭 수, 실수 방지, 힌트 문구와 동작의 일치에 집착한다. 웨어러블 UI를 많이 리뷰했다.
2. **윤지아 (31) · 타이포그래피 에디터** — 디자인 매거진 에디터. 단색 HUD의 미감, 자간·위계·여백, 문구 톤을 본다. 조잡한 기호와 흔들리는 레이아웃을 싫어한다.
3. **강태오 (37) · 하드웨어 리뷰어** — 웨어러블 전문. 배터리, 통신량, 지연, 안정성을 수치로 본다. 수치가 없으면 믿지 않는다.
4. **오민서 (33) · 통근 개발자** — 매일 왕복 1시간 반 지하철로 출퇴근하는 개발자 블로거. 주머니 속에서 알아서 되는지, 환승과 하차를 정확히 챙기는지를 본다.
5. **배수현 (36) · 가성비 칼럼니스트** — IT 칼럼니스트. 비용, 무료 한도, 유지보수, 노선 커버리지, 개인정보를 본다.

## 다음 작업 (라운드 5의 '있으면 좋은 것', 배포본은 건드리지 않았다)

실패·복구 경로
- 서울 INFO-100(키 무효)·INFO-300을 키 오류로 분류한다. 지금은 빈 목록으로 읽혀 '열차가 오지 않습니다'가 된다(api.ts rows). (배수현, 강태오)
- 주행 멈춤 화면(서버 실패·열차 끊김)의 탭을 '다시 확인'(resumeTrip)으로. 지금은 '처음으로' → 둘째 줄 이어가기(5분 한정)다. (한서준)
- 이어가기로 되살린 주행도 주행 요약을 남긴다(resumeTrip에서 ride를 새로 만든다). (강태오, 오민서)
- 직전 요청이 1분 넘게 전이면 실패 시작 시각을 새로 잡는다(failAt). (한서준)
- 실수 탭 복구 실패 화면에 '탭: 다시 확인'을 적는다. 고르기 멈춤 화면 머리줄을 '하계 7호선'으로, 문구는 '받지 못했습니다'로. (한서준, 윤지아)
- 멈춘 화면은 분 단위 시계로 그린다(아무도 안 보는 10분에 약 590회 쓰기). (강태오)

조판
- 두 정거장 전 화면의 줄 나눔을 '약'이 붙은 폭으로 정한다(다음 역 5~6자에서 추정이 바뀌면 화면이 뛴다). 추정·관측 화면의 줄 위치 비교 시험. (윤지아)
- ERROR-338 제목과 부제의 'key/키'를 맞추고 한 줄로. '빌드 토큰과 워커 비밀값이 다릅니다' 줄바꿈. api.ts 오류 문구와 main.ts 상수를 전수 시험에 넣는다. (윤지아, 배수현)
- Cloudflare 요청 기록 보관 고지를 스위치 설명 밖(조회 수 줄 옆)으로 옮기고 '스위치와 상관없이'를 붙인다. (배수현)
- 목록 첫 행 높이(실기기 세로 정렬 확인 뒤). (윤지아)

정확도
- 환승 뒤 자동 탑승을 첫 관측으로 다시 확인한다(관측 도착이 걷는 시간보다 이르면 다음 열차). (오민서)
- 다가오는 열차의 대기 화면 '약 N분'이 1분 안에서 늘어나지 않게 한다. (오민서)
